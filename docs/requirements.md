# Sukiyaki Ordering Prototype Requirements

## Goal
Build a beginner-friendly web prototype for a sukiyaki restaurant ordering system.

## Target Users
- Customers who order food at the table
- Staff who check order summaries

## Core Features
1. Show menu items with name, category, and price.
2. Add menu items to cart.
3. Remove items from cart.
4. Calculate total price.
5. Input table number.
6. Confirm order.
7. Show order summary.

## Constraints
- Use HTML, CSS, and JavaScript only.
- Use mock data only.
- No backend or database.
- Keep code simple for students.
