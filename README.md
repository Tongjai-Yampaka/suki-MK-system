# ระบบบริหารจัดการร้านสุกี้ (Suki System)

## 📝 บรรยาย
ระบบบริหารจัดการร้านสุกี้ เป็นเว็บแอปพลิเคชันที่ออกแบบมาเพื่อช่วยจัดการการดำเนินงานของร้านสุกี้ทั้งหมด

## ✨ ฟีเจอร์หลัก
- 📋 จัดการเมนูและราคาอาหาร
- 🛒 ระบบสั่งอาหารและชำระเงิน
- 👥 จัดการข้อมูลลูกค้า
- 📊 รายงานการขาย
- ⏰ จัดการเวลาทำการ
- 📞 ระบบการติดต่อและรีวิว

## 🚀 วิธีการใช้งาน
1. เปิดไฟล์ `index.html` ในเบราว์เซอร์
2. ไปที่เมนูหลักเพื่อเข้าใช้งาน
3. ปฏิบัติตามคำแนะนำในระบบ

## 🛠️ เทคโนโลยี
- HTML5
- CSS3
- JavaScript

## 📦 ไฟล์โครงสร้าง
```
suki-system/
├── index.html       # หน้าแรกของระบบ
├── README.md        # ไฟล์นี้
└── ...
```
