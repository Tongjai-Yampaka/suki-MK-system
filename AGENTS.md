# AGENTS.md

## Project Name
Agentic Sukiyaki Demo

## Project Goal
Build a beginner-friendly prototype for a sukiyaki restaurant ordering system using HTML, CSS, and JavaScript.

## Context
This project is used in Lab 1 of Agentic AI for Developers. Learners are practicing how to use opencode as a coding agent.

## Development Rules
- Explain the plan before editing files.
- Do not delete files without permission.
- Use only HTML, CSS, and JavaScript.
- Use mock data only.
- Do not use paid APIs.
- Do not install packages without permission.
- Keep code readable for beginners.
- Summarize all changed files after editing.

## Required Features
- Display menu items with price.
- Add items to cart.
- Remove items from cart.
- Calculate total price.
- Input table number.
- Confirm order.
- Show order summary.

## Safety Rules
- Do not expose secrets or API keys.
- Ask before making major structural changes.
- Do not run destructive commands.
- Always explain the reason before changing code.

## Output Expectation
The prototype should run in a browser by opening src/index.html.
